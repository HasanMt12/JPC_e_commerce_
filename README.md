# Chahida - Premium E-Commerce App

Chahida is a modern, high-performance Android application for organic product shopping. Built with Jetpack Compose, it offers a premium user experience with glassmorphism effects and smooth animations.

## Key Features
- **Modern UI**: Stylish design using a Gold & Dark theme.
- **Glassmorphism**: Beautiful blur effects using the Haze library.
- **Persistent Cart**: Your shopping cart is saved locally even if you close the app.
- **Dynamic Categories**: Filter products by category with a single tap.
- **Smooth Navigation**: Custom bottom bar and side drawer for easy access.
- **FAQ Section**: Interactive and expandable FAQ for customer support.
- **Local Order History**: View your past orders with photos and status tracking.
- **Social Integration**: Floating widget for quick WhatsApp, Messenger, and Facebook support.

## Tech Stack
- **Jetpack Compose**: Modern Android UI toolkit.
- **Retrofit**: Network API integration.
- **Coroutines & Flow**: Reactive data handling.
- **Haze**: Advanced glassmorphism effects.
- **Coil**: Efficient image loading.
- **GSON**: Data serialization.

## API Endpoints Used
- `/api/products`: Fetch all organic products.
- `/api/categories`: Fetch categories with visibility control.
- `/api/faq`: Fetch frequently asked questions.
- `/api/orders`: Place new orders.
- `/api/website-info`: Fetch brand metadata and social links.

## Getting Started
1. Clone the repository.
2. Open in Android Studio.
3. Sync Gradle dependencies.
4. Run on an emulator or physical device.
